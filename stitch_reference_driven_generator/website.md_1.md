# Mritunjay Website Architecture

Version 1.0

---

# Website Goal

The website should introduce a completely new way of thinking about healthcare.

Visitors should leave with one clear understanding:

"Mritunjay continuously understands people, making healthcare more personalized over time."

The website is not a SaaS landing page.

It is a product story.

---

# Primary Objectives

Build trust.

Create curiosity.

Explain the product.

Demonstrate credibility.

Generate demo requests.

Build excitement around the future of healthcare.
