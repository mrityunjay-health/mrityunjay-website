# motion.md

# Mritunjay Motion Language

Version 1.0

---

# Philosophy

Motion is not decoration.

Motion explains intelligence.

Every animation should communicate that understanding is growing.

Nothing moves without purpose.

---

# Core Feeling

Calm.

Organic.

Living.

Scientific.

Elegant.

Never frantic.

Never playful.

Never futuristic for the sake of it.

---

# Motion Keywords

Grow.

Connect.

Flow.

Organize.

Learn.

Remember.

Evolve.

Reveal.

Understand.

---

# Hero Animation

The hero is the signature experience.

Sequence:

Silence.

↓

Single point of light.

↓

Gentle pulse.

↓

Organic branching.

↓

Health signals appear.

↓

Signals connect.

↓

Connections strengthen.

↓

A living health intelligence network emerges.

↓

Headline fades in.

Never begin with text.

Let curiosity build first.

---

# Particle System

Particles represent information.

Not stars.

Not dust.

Not decoration.

Each particle represents:

Symptoms.

Conversations.

Lifestyle.

Medication.

Biomarkers.

Health events.

Particles move with intention.

Never randomly.

---

# Connections

Connections form gradually.

They strengthen over time.

Unused paths fade softly.

Important paths become brighter.

The network should appear to learn.

---

# Scroll Behavior

Scrolling should reveal knowledge.

Every section introduces one new concept.

Never reveal everything at once.

Transitions should feel seamless.

---

# Reveal Animations

Prefer:

Fade

Scale (very subtle)

Blur to focus

Organic line drawing

Progressive reveal

Avoid:

Bounce

Flip

Spin

Zoom explosions

Overshooting animations

---

# Timing

Fast interactions:

150-250 ms

Standard:

300-500 ms

Storytelling:

700-1500 ms

Hero sequence:

6-10 seconds

Animations should feel patient.

Healthcare is not a game.

---

# Mouse Interaction

Respond subtly.

Background shifts.

Network responds.

Particles acknowledge the cursor.

Avoid exaggerated parallax.

---

# Health Memory Visualization

Every interaction adds knowledge.

The visualization should evolve over time.

It should never reset.

The structure should appear to remember previous states.

---

# Section Transitions

Transitions should feel like turning the page of a scientific journal.

Smooth.

Continuous.

Intentional.

---

# Loading States

Loading should communicate progress.

Avoid generic spinners.

Use flowing lines.

Growing connections.

Subtle pulses.

---

# CTA Motion

Buttons should respond with confidence.

Small elevation.

Soft highlight.

Quick response.

Never flashy.

---

# Micro Interactions

Cards gently lift.

Icons draw themselves.

Lines extend naturally.

Graphs build progressively.

Numbers count smoothly.

Everything feels alive.

---

# Background Motion

Very subtle.

Slow gradients.

Soft moving particles.

Organic line movement.

Never distracting.

---

# Animation Libraries

Primary:

* anime.js

Optional:

* Framer Motion
* Motion One
* GSAP (only where necessary)

Prefer anime.js for signature visuals because it excels at SVG path animation, timelines, particle orchestration, and smooth choreography.

---

# Performance Rules

Maintain 60 FPS on modern devices.

Respect reduced-motion preferences.

Pause heavy animations when off-screen.

Avoid unnecessary continuous rendering.

Optimize SVGs and canvas effects.

---

# Signature Rule

If someone watches the homepage for five seconds with the text hidden, they should still feel that the system is quietly learning, connecting information, and becoming more intelligent.

Every animation should reinforce that single idea.
