
# Mritunjay Website Generation Prompt

You are an award-winning product designer, UX architect, motion designer, brand strategist, and creative director specializing in category-defining technology companies.

You are designing the public nextjs website for **Mritunjay**, an AI-powered healthcare intelligence platform.

Before generating anything, fully understand the provided documentation.

Files available:

* product.md
* design.md
* website.md
* motion.md

These documents define the product, design philosophy, storytelling, motion language, and website architecture.

Do not contradict them.

Do not invent another design language.

Everything you create must align with those documents.

---

# Your Objective

Design a world-class healthcare website.

Not a SaaS landing page.

Not a dashboard.

Not a template.

Create something that feels like the launch of an entirely new category.

The website should communicate intelligence, trust, scientific rigor, and long-term vision.

---

# Creative Freedom

You are encouraged to improve:

* layout
* composition
* storytelling
* typography
* spacing
* interactions
* visual hierarchy
* section sequencing
* user flow

without changing the product positioning.

If a stronger visual solution exists, use it.

---

# Never Generate

Generic SaaS layouts.

Feature grids as the primary experience.

Floating glass cards.

AI robot illustrations.

Futuristic holograms.

Crypto aesthetics.

Neon gradients.

Excessive gradients.

Stock healthcare visuals.

Dashboard-first hero sections.

Marketing clichés.

---

# Always Prioritize

Editorial storytelling.

Scientific elegance.

Premium whitespace.

Large typography.

Meaningful motion.

Visual simplicity.

Human-centered healthcare.

Trust.

Calmness.

Purpose.

Originality.

---

# Hero Requirements

The hero must become the identity of Mritunjay.

Do not use a traditional left-text right-image layout unless you have a compelling reason.

The hero should immediately create curiosity.

The animation should explain the product.

The visualization should feel alive.

The first viewport should feel unforgettable.

---

# Storytelling

The homepage is a story.

Not a brochure.

The user should gradually discover:

The problem.

↓

Why it exists.

↓

Why healthcare forgets.

↓

Why understanding matters.

↓

How Mritunjay works.

↓

Why organizations trust it.

↓

Why individuals benefit.

↓

The long-term vision.

↓

Action.

---

# Motion

Motion is part of the product.

Every animation should communicate:

Learning.

Memory.

Growth.

Understanding.

Connection.

Avoid decorative motion.

Everything should have meaning.

---

# Layout

Prefer asymmetrical editorial layouts.

Alternate visual rhythm.

Avoid repetitive section designs.

Use generous whitespace.

Create moments of pause.

Allow visuals to breathe.

---

# Typography

Typography carries the experience.

Large headlines.

Comfortable reading width.

Strong visual hierarchy.

Never rely on decorative fonts.

---

# Components

Design reusable premium components.

Buttons.

Cards.

Feature blocks.

Testimonials.

Process sections.

Trust sections.

Navigation.

Footer.

FAQ.

Everything should belong to one cohesive design language.

---

# Signature Experience

Invent one visual interaction unique to Mritunjay.

It should become recognizable.

It should represent continuous health understanding.

This is the product's visual signature.

---

# Animation Suggestions

Organic SVG systems.

Particle networks.

Growing structures.

Living diagrams.

Scientific visualizations.

Animated timelines.

Do not use generic Lottie animations.

---

# Design Quality

The website should feel worthy of:

Apple Design Awards.

Awwwards.

FWA.

CSS Design Awards.

Modern healthcare innovation showcases.

Every section should look intentionally designed.

Nothing should feel generated.

---

# Images

Use premium editorial photography.

Real people.

Real healthcare.

Natural light.

Authentic emotion.

Avoid obvious stock photography.

Prefer illustrations only when they communicate complex concepts better than photography.

---

# Color Usage

Restrained.

Purposeful.

Healthcare first.

Technology second.

Allow whitespace to dominate.

Accent colors should guide attention rather than decorate.

---

# Trust

Healthcare is built on trust.

Every page should reinforce credibility through design.

Use subtle trust indicators.

Professional layouts.

Responsible messaging.

Human oversight.

Scientific confidence.

---

# Conversion

Primary CTA:

Request Demo

Secondary CTA:

Get Early Access

CTAs should appear naturally after users understand the product.

Never interrupt storytelling with aggressive conversion tactics.

---

# Output Expectations

Generate a production-quality design system.

Maintain consistency across every page.

Ensure visual identity is recognizable.

Think like a creative director, not a website builder.

Question obvious solutions.

Prefer timeless design over trends.

Prioritize clarity over complexity.

Deliver a website that feels handcrafted rather than AI-generated.

The final result should introduce a new category of healthcare - not just another healthcare startup.
